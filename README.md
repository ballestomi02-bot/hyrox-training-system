# HYROX Training System

Aplicación web mobile-first para registrar y revisar entrenamientos de HYROX, fuerza y running.

## Primera versión

- Dashboard semanal con kilómetros, sesiones, minutos y volumen de fuerza.
- Plan semanal base: HYROX técnica, fuerza full body, running aeróbico, HYROX resistencia, descanso, estaciones y running base.
- Registro de sesiones con duración, RPE, distancia, ritmo, volumen de fuerza, ejercicios y notas.
- Historial de entrenamientos con opción de borrar registros.
- Check-in de recuperación: sueño, energía, fatiga, estrés y dolor.
- Interfaz adaptable a móvil, con estética oscura y acentos verde oliva.

## Cómo probarla

Abrí `index.html` en un navegador o habilitá GitHub Pages desde Settings → Pages, seleccionando la rama `main` y la carpeta `/ (root)`.

## Datos y privacidad

Esta primera versión guarda los registros en `localStorage` del navegador/dispositivo. No hay sincronización en la nube todavía. Si se borran los datos del navegador o se cambia de dispositivo, los registros no se transfieren automáticamente. No cargues información sensible.

## Próximas etapas

1. Mejorar el registro por ejercicios y series.
2. Agregar gráficos de evolución y métricas por estación.
3. Añadir exportación e importación de respaldos.
4. Evaluar autenticación y base de datos para sincronización entre dispositivos.

Las cargas sugeridas son orientativas y deben ajustarse a la técnica, RPE y tolerancia individual. La app no reemplaza asesoramiento profesional.
